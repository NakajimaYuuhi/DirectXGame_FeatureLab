# ファイルエンコーディング規約と高速変換ツールの利用規約

## 1. 概要
本プロジェクトは Windows 環境および Visual Studio (MSVC) を使用して開発されています。
日本語コメントや文字列リテラルの文字化け・コンパイルエラー（C4819警報や2バイト文字による構文エラーなど）を防ぐため、C++ および HLSL のソースコードファイルはすべて **Shift_JIS (CP932)** エンコーディングで保存してください。

---

## 2. 適用対象ファイル
以下の拡張子を持つすべてのファイル：
- **C++ 関連**: `.cpp`, `.c`, `.h`, `.hpp`, `.inl`
- **HLSL / シェーダー関連**: `.hlsl`, `.hlsli`, `.fx`

---

## 3. AIエージェントへの特別指示（トークン節約＆変換実行規定）

### 3.1. 新規ファイルの作成・編集
- 対象ファイルを新規作成・編集・保存する際は、必ず **Shift_JIS (CP932)** エンコーディングを指定して保存すること。

### 3.2. 既存ファイルの文字コード判定・変換時（最重要）
- 既存ファイルの文字コード変換や、フォルダ単位での文字コード一括変換・確認を行う際、**ファイル全体を会話コンテキスト（`view_file` や `write_to_file`）に無駄に読み書きしてトークンを消費しないこと**。
- 代わりに、プロジェクト内に設置された専用ツール `scripts/convert_to_sjis.ps1` をコマンドで直接実行して、ローカルで高速変換・保存処理を行うこと。

#### 実行コマンド形式:
* **フォルダ一括変換時**:
  ```powershell
  powershell -ExecutionPolicy Bypass -File scripts/convert_to_sjis.ps1 "<フォルダパス>"
  ```
* **単一ファイル変換時**:
  ```powershell
  powershell -ExecutionPolicy Bypass -File scripts/convert_to_sjis.ps1 "<ファイルパス>"
  ```

---

## 4. 文字化け防止措置
- 変換処理において、UTF-8 特有の文字（Unicode波線 `〜` など）は CP932 互換文字へ安全に正規化して保存すること（`scripts/convert_to_sjis.ps1` 内で自動処理されます）。
