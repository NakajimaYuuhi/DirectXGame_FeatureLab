# ファイルエンコーディング規約と変換ツールの利用規約

## 1. 概要
本プロジェクトは Windows 環境および Visual Studio (MSVC) を使用して開発されています。
日本語コメントや文字列リテラルの文字化け・コンパイルエラー（C4819警告や2バイト文字による構文エラーなど）を防ぐため、C++ および HLSL のソースコードファイルはすべて **Shift_JIS (CP932)** エンコーディングで保存してください。

---

## 2. 適用対象ファイル
以下の拡張子を持つすべてのファイル：
- **C++ 関連**: `.cpp`, `.c`, `.h`, `.hpp`, `.inl`
- **HLSL / シェーダー関連**: `.hlsl`, `.hlsli`, `.fx`

---

## 3. 変換ツール (`to_sjis.py`) の利用規定

文字コードの変換および検証には、プロジェクト直下の `to_sjis.py` (または `python to_sjis.py`) を使用します。

### 実行コマンド形式:
* **特定ファイル・複数ファイルの変換**:
  ```powershell
  python to_sjis.py <ファイルパス1> [<ファイルパス2> ...]
  ```
* **特定フォルダの再帰変換**:
  ```powershell
  python to_sjis.py <フォルダパス>
  ```
* **Source フォルダ全体の自動一括変換（引数なし）**:
  ```powershell
  python to_sjis.py
  ```

---

## 4. 文字化け防止措置
- 変換処理において、UTF-8 特有の波線（Unicode波線 `～` U+301C）は CP932 互換波線（`～` U+FF5E）へ安全に正規化して保存されます。
- すでに Shift_JIS (CP932) で正しくエンコードされているファイルは誤って二重変換・破損しないよう自動保護されます。
